# Burgundy Motion

このゲーム用に新規作成したオリジナルのインストゥルメンタルです。既存楽曲の引用、外部録音、サンプルパック、外部APIは使用していません。音色と楽譜は `music.js`、ノイズとミキサーは `audio.js` に含まれます。

134 BPM、Dメジャーを中心とするコード、4つ打ちキック・クラップ・ハイハット・ベース・パッド・アルペジオ・リード・スイープを組み合わせます。32小節（導入8／ビルド4／ドロップ12／ブレイク4／リターン4）。距離による編成は小節境界で適用します。

`burgundy-motion-preview.mp3` は最も楽器が多いプレイ編成の34小節（約61秒）。32小節の後のループ境界も収録しました。ゲームと同じ音源をOfflineAudioContextで生成し、MP3に変換しています。ゲーム本体はこのファイルをダウンロードせず、約10KBのシーケンサーから発音します。

再生成はローカルHTTPサーバー起動後に `RENDER_PREVIEW=1 node tests/presentation-browser.cjs` を実行し、`work/burgundy-motion.wav` をMP3へ変換します。音量値はSFX 70％、BGM 35％、マスター85％です。聴感の評価は実際のスピーカー・イヤホンで行ってください。
