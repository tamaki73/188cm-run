# 188cm RUN

身長188cmの人物になって、街の入口を走り抜けるオリジナルのランゲームです。Canvasの疑似3Dで、電車の入口、地下通路、倉庫、体育館、駐車場などが奥から迫ります。入口の形と頭上の余裕を見て、姿勢を選んでください。

ゲーム本体はHTML・CSS・JavaScriptだけで動きます。外部画像、ライブラリ、APIキー、有料サービスは使いません。

## ブラウザで遊ぶ

GitHub Pagesを有効にすると、次のURLで遊べます。

**https://tamaki73.github.io/188cm-run/**

初回は7ステップのチュートリアルが自動で始まります。画面を一度クリックして、キーボードを操作してください。

## Google Colabで遊ぶ

[Colabでノートブックを開く](https://colab.research.google.com/github/tamaki73/188cm-run/blob/main/188cm_RUN.ipynb)

1. 上のリンクを開きます。Google Colabを利用する場合はGoogleへのログインが必要です。ゲーム本体には専用アカウントは不要です。
2. 必要なら上部の「接続」を押します。
3. **セル1 → セル2 → セル3**の順に、各セル左側の「▶」を押します。「このノートブックはGoogleが作成したものではありません」という確認が出た場合は、コードを確認して「このまま実行」を選びます。
4. セル3の下にゲーム画面が表示されます。ゲーム画面を一度クリックします。
5. チュートリアルの説明に沿ってキーを押し、「次へ」で進みます。

ノートブック内に完成版ゲームのコードをすべて収録しています。GitHubからのゲームファイル取得やpipインストールは不要です。PythonがHTMLファイルを生成し、バックグラウンドのHTTPサーバーを起動し、Colabの `serve_kernel_port_as_iframe()` で表示します。

ノートブックをダウンロードしてColabの「ファイル → ノートブックをアップロード」から開く方法も使えます。新しいノートブックにコードを貼る場合は、[colab_cells.py](colab_cells.py) の `# %%` で区切られた3つのセルを、上から順番にコピーしてください。

サーバー起動セルは再実行でき、前のサーバーを停止してから新しいポートで起動します。再実行後はセル3も実行してください。Colabのランタイムが切断された場合は、3つのセルを再実行します。

## 操作とルール

| キー | 操作 |
| --- | --- |
| 何も押さない | 立ったまま自動走行 |
| ↓ / Shift | 押している間しゃがむ。離すと立つ |
| Space | ジャンプ |
| E | 近づいたアイテムへ手を伸ばす |
| Enter | ゲームオーバー後にリスタート |
| Esc | 一時停止 / 再開 |

しゃがむ必要がある入口は、通過を始めてから抜けるまでキーを押し続けます。ジャンプ中は頭の位置も高くなります。通常プレイ中に入口の高さや正解操作は表示しません。

アイテムは、近づいたタイミングで **E** を押したときだけ取れます。低いアイテムは立った状態で、高いアイテムはジャンプ中に取ります。Eの長押しで自動取得はできません。取り逃がしてもゲームオーバーにはなりません。

スコアは走行距離1mにつき10点、低いアイテムは300点、高いアイテムは500点です。走るほど速度が上がります。イベントの順番と間隔は毎回変わり、同じ種類が続きすぎないよう調整しています。

しゃがみ続けると負荷が増え、立って走ると回復します。ジャンプも足首の負荷を増やし、こちらはゆっくり回復します。合計100%になるとゲームオーバーです。負荷やけがはゲーム上の演出です。

画面から離れると自動で一時停止します。「ゲームに戻る」を押すと3秒後に再開します。音は初期状態でオフです。画面下の「音：オフ」を押すとオンにできます。スマートフォン用のタッチボタンも用意しています。

## チュートリアルの設定

「次回からチュートリアルを表示しない」をチェックすると、スキップボタンが有効になります。チェックだけではゲームは開始しません。スキップボタンを押すと通常プレイが始まります。

設定と自己ベストはブラウザのlocalStorageに保存します。保存領域を利用できないiframeやブラウザでもゲームは動きますが、次回の起動には設定を引き継げません。タイトル画面からは、いつでもチュートリアルをやり直せます。

## GitHub Pagesの公開設定

最初の一度だけ、リポジトリ管理者が設定します。

1. [リポジトリのPages設定](https://github.com/tamaki73/188cm-run/settings/pages)を開きます。
2. **Build and deployment → Source**で **Deploy from a branch** を選びます。
3. **Branch**を **main**、フォルダーを **/ (root)** にして **Save** を押します。
4. 数分待ち、設定画面に表示される **Visit site** を押します。

公開URLは https://tamaki73.github.io/188cm-run/ です。公開には認証が不要で、誰でもアクセスできます。404が続く場合は、Pages設定のブランチとフォルダーを確認し、[Actions](https://github.com/tamaki73/188cm-run/actions)のPagesビルドが成功しているか確認してください。

以降はmainブランチのゲームファイルを更新すると、Pagesにも反映されます。`.nojekyll` により、静的ファイルをそのまま配信します。

## 開発と調整

| ファイル | 内容 |
| --- | --- |
| `index.html` | 日本語UI、画面、ボタン |
| `style.css` | レイアウト、デザイン、レスポンシブ表示 |
| `game-engine.js` | 状態、物理、負荷、イベント、衝突、チュートリアル |
| `game.js` | Canvas描画、入力、フォーカス、一時停止、音 |
| `188cm_RUN.ipynb` | 完成版を内包するColabノートブック |
| `colab_cells.py` | 同じ内容を3セルとして貼り付けられるPythonコード |
| `tools/build_colab.py` | ゲームのソースからColab用成果物を再生成 |
| `tests/` | ルール、ブラウザ操作、ノートブックの検証 |

`game-engine.js` 冒頭の `CONFIG` で速度、イベント間隔、ジャンプ、負荷を調整できます。物理は秒を基準に120Hzの小ステップで計算し、描画にはrequestAnimationFrameを使います。障害物は通過中の全時間に衝突判定を行います。描画上の188cmと判定上の188cmは同じ高さです。

ローカルで起動する場合：

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。Pythonがない場合でも、`index.html` を直接開いて遊べます。

ソース変更後の確認：

```sh
node --check game-engine.js
node --check game.js
node tests/engine.test.js
python3 tools/build_colab.py
python3 tests/colab_test.py
```

ブラウザテストはPlaywrightとChromiumを使います。開発テスト用に `npm install --no-save playwright` を実行し、Chromiumを用意してから、上記HTTPサーバーを起動した状態で `node tests/browser.cjs` を実行します。必要なら `CHROMIUM_PATH` と `GAME_TEST_URL` でパスとURLを指定できます。通常プレイにはこれらのインストールは不要です。

`?test` を付けたURLだけに内部状態を確認できるテスト用オブジェクトを公開します。通常のURLでは公開しません。

## 検証範囲

クラウド環境のChromiumで、実際のキーボード入力とiframe内の操作を検証します。Colab用コードはローカルで3セルを実行し、HTML生成、HTTP応答、サーバー再実行、iframe表示APIへの引数を検証します。

Google Colab本体へのログインとColab独自のプロキシ表示は、この開発環境から直接確認できません。実際のColabでの表示確認は、上記の3セルを順番に実行して行ってください。
