# 188cm RUN

身長188cmの高校生・大学生として、日常の不便さと身体能力を体験するランゲームです。既存のCanvasゲームを拡張し、通学路、学校・大学、電車・駅、路線バス、コンビニ・スーパー、公園、自宅の7エリアを走ります。頭上と足元を見て、しゃがみ・またぎ・ジャンプ・取得を使い分けてください。

黒とバーガンディのガラス風UIで、広いゲーム画面と2両の立体ミニ電車を採用しています。前回の変更は [統合アップデート報告](UPDATE_REPORT.md)、前回の説明欄・効果音は [追加修正20〜22](AUDIO_UPDATE_REPORT.md)、最新のタイトル縮小・左側説明欄・音声修正は [今回の修正報告](MENU_SOUND_REPORT.md) を参照してください。

ゲーム本体はHTML・CSS・JavaScriptだけで動き、外部画像・APIキーは不要です。任意のオンラインランキングのみFirebase Web SDK（13.0.0）とFirebaseの無料プロジェクト設定を使用します。**Firebaseプロジェクト `cm-run` のWeb設定は反映済みです。公開後の本番ランキング動作は未確認です。[初心者向けの設定手順](ONLINE_SETUP.md)をご覧ください。**

## 操作とルール

| キー | 操作 |
| --- | --- |
| 何も押さない | 立ったまま自動走行 |
| ↓ / Shift | 押している間しゃがむ。離すと立つ |
| S | 押している間、脚を左右に広げてまたぐ |
| Space | ジャンプ |
| E | 近づいたアイテムへ手を伸ばす |
| Enter | ゲームオーバー後にリスタート |
| Esc | 一時停止 / 再開 |

しゃがむ必要がある入口は、通過を始めてから抜けるまでキーを押し続けます。ジャンプ中は頭の位置も高くなります。通常プレイ中に入口の高さや正解操作は表示しません。

アイテムは、近づいたタイミングで **E** を押したときだけ取れます。低いアイテムは立った状態で、高いアイテムはジャンプ中に取ります。Eは約0.4秒間予約され、予約中に距離と到達高度が合えば取得します。1回の入力で取るのは1個だけです。Eの長押しで自動取得はできません。**通常プレイでは取り逃がすとゲームオーバーです。** 原因にはアイテム名が表示されます。チュートリアル中は同じステップで再挑戦できます。

スコアは走行距離1mにつき10点、低いアイテムは300点、高いアイテムは500点です。走るほど速度が上がります。イベントの順番と間隔は毎回変わり、同じ種類が続きすぎないよう調整しています。

しゃがみの負荷は連続した時間に応じ、最初の2秒は毎秒15%、2〜4秒は25%、4秒以上は35%です。ごく短い立ち上がりでは段階をリセットできません。またぎは毎秒20%、ジャンプは1回12%が加算されます。通常走行は合計で毎秒8%回復します。ジャンプ中なども足首は毎秒2%ずつ回復します。表示ゲージは1本で、100%になると終了します。

ゲージは60%から黄色、80%からオレンジと軽い警告、95%から赤と控えめな警告音になります。音はオンにした場合のみ鳴ります。「演出：通常」を押すと警告のアニメーション・警告音・粒子を弱められ、設定を保存します。OSの「動きを減らす」設定も初期値に反映します。

しゃがみで限界に達すると「ヘルニアになりました」、またぎで限界に達すると「股関節が限界を迎えました」、ジャンプは足首の専用メッセージを表示します。病名はゲーム内のコミカルな演出です。

これらはゲーム上の設定と演出です。遊具や架空の標識に触れたり飛び越えたりする現実の行動を勧めるものではありません。

画面から離れると自動で一時停止します。「ゲームに戻る」を押すと3秒後に再開します。音は初期状態でオフです。画面下の「音：オフ」を押すとオンにできます。スマートフォン用のタッチボタンも用意しています。

## 身体能力とアイテムの高さ

身長188cm、靴込みの通行判定190cm、股下90cm、垂直跳び75cm、立ち到達252cm、ジャンプ最高到達327cmを基準にします。低いアイテムは252cm以下、高いアイテムは252cm超〜327cmです。高い物は単に空中にいればよいのではなく、現在の手の高度が届くタイミングでEを押します。少し早い入力も0.4秒間予約されるため、頂点の1フレームに合わせる必要はありません。

通常プレイのミニ電車は前面・側面・上面・連結車を描き、約0.75秒の間Sを保持します。途中で離すと衝突するので、車体の後端まで維持してください。チュートリアルの電車は従来の判定のままです。

車線分離ポール、ミニ電車、スーツケース、カラーコーン1個、跳び箱5段は、ゲーム内の専用ルールでSを保持してまたぎます。幅80cmを超える物や、股下に収まらない高さの物にはまたぎが通用しません。パンダ・ゾウ・カメ・ウマのスプリング遊具や、横に並ぶカラーコーン2個はジャンプで回避します。足元が障害物より高い状態で、奥行き全体を通過する必要があります。

## 難易度と安全なイベント生成

速度は0mで1倍、100mで1.4倍、200mで1.9倍、300mで2.4倍、500mで3.1倍、800m以降は3.5倍に滑らかに変化します。通常の間隔抽選は前版から12%短縮しています。序盤は約2.20〜3.08秒を基本に、走るほど自然にテンポが上がります。着地・前イベントの後端・取得の時間幅・疲労回復を優先し、必要なら延期します。ジャンプの後は1.3秒以上、長いミニ電車の後は後端から0.8秒以上の余裕を残します。

イベントの到着時刻を先に決め、加速を見込んで位置を計算します。各イベントは最低3.4秒先に配置します。1秒のジャンプ滞空時間に0.3秒の操作余裕を加え、ジャンプの後でも着地して姿勢を切り替えられます。取得可能距離は到着時の速度を基準に計算し、約0.84秒の時間幅を確保します。

生成時は正しい操作に必要な負荷を保守的に見積もります。通常の候補は予測負荷55%を基準に選び、必要なら延期します。中盤から時々、長い吊り革・網棚・バス天井・部室・鴨居・古い出入口の通路が現れます。正しい操作で蓄積する疲労が回復してから入るよう配置し、約3.9秒の通過と操作の余裕で負荷が80〜95%に達する緊張感を作ります。通過後は回復できる入口と低いアイテムだけを出し、負荷が下がる時間を確保します。加速中も通路を抜ける時間が一致するよう、前後端の位置を計算します。

一部の長い通路には、その1.3秒前に立ったまま通れる扉が出ます。無駄に長くしゃがむと疲労が残り、後の通路で限界に達することがあります。短い誤操作は回復できます。長い区間と導入扉はテンポ調整後の集計上の約9%で、連続させず、通過後に回復時間を確保します。

イベントの生成時刻も到着予定に合わせ、長い区間を入れても遠方イベントが無制限に積み上がらないようにしています。通常プレイ中の表示は、上部中央に次の1イベントの名前だけです。障害物ごとの高さや正解は表示しません。右端の190cm目盛りはプレイヤーの立位の基準です。

既存の障害物19種類とアイテム21種類を維持し、「古い建物の低い出入口」を加えています。エリアは180mごとに変わり、開始・再スタートごとに7エリアの並びをシャッフルします。到着先のエリア・予測疲労に適合する候補から、種類数の多いアイテムが他の操作を圧迫しないよう動作グループ単位で抽選します。同じイベントを直後には繰り返しません。チュートリアルの順番は固定です。

## オンラインランキングと理解度

タイトルとゲームオーバー画面からランキングを開けます。初回の通常プレイ開始前（チュートリアル完了・スキップ後も含む）にニックネームを設定でき、設定後は同じブラウザで再利用できます。名前なしでも通常プレイを続けられます。ランキング画面で名前を変更できます。入力のすぐ下には「※本名は入力しないでください。ニックネームはランキングで公開されます。」を常時表示します。例はRUNNER188で、本名を求めません。

ランキングはアイテム点を含まず、ゲームオーバー時の走行距離で上位10人を表示します。同じ匿名IDの自己ベストだけを保存し、理解度は `min(100, floor(距離 / 10))` で計算します。1000mを超えても距離と順位は伸び続けます。理解度は能力・難易度には影響しません。

未設定・通信エラー・送信制限中でもゲームは遊べます。本番共有は[ONLINE_SETUP.md](ONLINE_SETUP.md)のFirebase設定が必要です。

## 見やすい追従カメラ

視点を少し上げ、斜め下を見下ろして前方の地面を広く見せます。キャラクターは画面下寄りに置き、小さい障害物と画面上で重なったときだけ半透明になります。キャラクターと障害物の描画には同じ高さ換算を使います。カメラ位置と半透明の条件は今回変更していません。

取得時は一定長の腕をアイテム方向へ伸ばし、高い取得では肩を少し上げます。ジャンプの高さと滞空時間・到達高度・取得判定・E予約はそのままです。背景は絶対的なワールド位置から描画し、繰り返し境界で左右や模様が入れ替わる問題を修正しました。空・建物は最大7種類をキャッシュし、エリアの色を40mかけて滑らかに混ぜます。0.5秒を超える停止は一時停止して、見えない間の大きな移動を防ぎます。

## 画面サイズとガラス表示

PCでは余白を減らし、画面の高さも考慮して最大1440pxまで広げます。Canvasの論理座標960×680は維持し、DPIに合わせて描画解像度を最大2倍にします。モバイルは縦横比を保って画面全体を表示し、パネルは画面の下に置きます。

対応環境のパネルだけに軽いぼかしを使い、非対応では暗い背景に切り替えます。スマートフォンと「演出：弱め」ではぼかしを減らします。危険度の色は従来の緑・黄・橙・赤のままです。

## 開発と調整

| ファイル | 内容 |
| --- | --- |
| `index.html` | 日本語UI、画面、ボタン |
| `style.css` | レイアウト、デザイン、レスポンシブ表示 |
| `game-engine.js` | 状態、物理、負荷、イベント、衝突、チュートリアル |

`game-engine.js` 冒頭の `CONFIG` で速度、イベント間隔、ジャンプ、負荷を調整できます。物理は秒を基準に120Hzの小ステップで計算し、描画にはrequestAnimationFrameを使います。障害物は通過中の全時間に衝突判定を行います。身長188cmに靴の高さ2cmを加え、描画と通行判定の頭頂は190cmで一致します。股下90cm、垂直跳び75cm、立ち到達252cm、ジャンプ到達327cmを定数管理しています。ジャンプ中の手の高度と足元の高度を別々に判定し、手の当たり判定には2cmの余裕があります。

ローカルで起動する場合：

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。Pythonがない場合でも、`index.html` を直接開いて遊べます。

```sh
node --check game-engine.js
node --check game.js
node --check audio.js

python3 tools/build_colab.py
```

`node tests/menu-browser.cjs` はタイトルの縮小・ボタン・PC左側配置、初回ON/40％と明示的OFFの保持、再開後の確認音、AudioContextの再開/再作成、音量の実波形を検証します。

`node tests/audio-browser.cjs` は説明欄の非重複、発音イベント、ミュート・音量の保存、実Web Audio波形と最大同時数を確認します。

`?test` を付けたURLだけに内部状態を確認できるテスト用オブジェクトを公開します。通常のURLでは公開しません。
