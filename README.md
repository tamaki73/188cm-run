# 188cm RUN

身長188cmの高校生・大学生として、日常の不便さと身体能力を体験するランゲームです。既存のCanvasゲームを拡張し、通学路、学校・大学、電車・駅、路線バス、コンビニ・スーパー、公園、自宅の7エリアを走ります。頭上と足元を見て、しゃがみ・またぎ・ジャンプ・取得を使い分けてください。

ゲーム本体はHTML・CSS・JavaScriptだけで動きます。外部画像、ライブラリ、APIキー、有料サービスは使いません。

## ブラウザで遊ぶ

公開版は次のURLで遊べます。更新はレビュー済みPull Requestをmainへマージした後に反映されます。

**https://tamaki73.github.io/188cm-run/**

初回は9ステップのチュートリアルが自動で始まります。画面を一度クリックして、キーボードを操作してください。

## Google Colabで遊ぶ

[Colabでノートブックを開く](https://colab.research.google.com/github/tamaki73/188cm-run/blob/main/188cm_RUN.ipynb)

1. 上のリンクを開きます。Google Colabを利用する場合はGoogleへのログインが必要です。ゲーム本体には専用アカウントは不要です。
2. 必要なら上部の「接続」を押します。
3. **セル1 → セル2 → セル3**の順に、各セル左側の「▶」を押します。「このノートブックはGoogleが作成したものではありません」という確認が出た場合は、コードを確認して「このまま実行」を選びます。
4. セル3の下にゲーム画面が表示されます。ゲーム画面を一度クリックします。
5. チュートリアルの説明に沿ってキーを押し、「次へ」で進みます。

ノートブック内に完成版ゲームのコードをすべて収録しています。GitHubからのゲームファイル取得やpipインストールは不要です。PythonがHTMLファイルを生成し、バックグラウンドのHTTPサーバーを起動し、Colabの `serve_kernel_port_as_iframe()` で表示します。

ノートブックをダウンロードしてColabの「ファイル → ノートブックをアップロード」から開く方法も使えます。新しいノートブックにコードを貼る場合は、[colab_cells.py](colab_cells.py) の `# %%` で区切られた3つのセルを、上から順番にコピーしてください。

サーバー起動セルは再実行でき、前のサーバーを停止してから新しいポートで起動します。再実行後はセル3も実行してください。Colabのランタイムが切断された場合は、3つのセルを再実行します。

## 操作とルール

| キー | 操作 |
| --- | --- |
| 何も押さない | 立ったまま自動走行 |
| ↓ / Shift | 押している間しゃがむ。離すと立つ |
| S | 押している間、脚を左右に広げてまたぐ |
| Space | ジャンプ |
| E | 近づいたアイテムへ手を伸ばす |
| Enter | ゲームオーバー後にリスタート |
| Esc | 一時停止 / 再開 |

しゃがむ必要がある入口は、通過を始めてから抜けるまでキーを押し続けます。ジャンプ中は頭の位置も高くなります。通常プレイ中に入口の高さや正解操作は表示しません。

アイテムは、近づいたタイミングで **E** を押したときだけ取れます。低いアイテムは立った状態で、高いアイテムはジャンプ中に取ります。Eは約0.4秒間予約され、予約中に距離と到達高度が合えば取得します。1回の入力で取るのは1個だけです。Eの長押しで自動取得はできません。**通常プレイでは取り逃がすとゲームオーバーです。** 原因にはアイテム名が表示されます。チュートリアル中は同じステップで再挑戦できます。

スコアは走行距離1mにつき10点、低いアイテムは300点、高いアイテムは500点です。走るほど速度が上がります。イベントの順番と間隔は毎回変わり、同じ種類が続きすぎないよう調整しています。

しゃがみの負荷は連続した時間に応じ、最初の2秒は毎秒15%、2〜4秒は25%、4秒以上は35%です。ごく短い立ち上がりでは段階をリセットできません。またぎは毎秒20%、ジャンプは1回12%が加算されます。通常走行は合計で毎秒8%回復します。ジャンプ中なども足首は毎秒2%ずつ回復します。表示ゲージは1本で、100%になると終了します。

ゲージは60%から黄色、80%からオレンジと軽い警告、95%から赤と控えめな警告音になります。音はオンにした場合のみ鳴ります。「演出：通常」を押すと警告のアニメーション・警告音・粒子を弱められ、設定を保存します。OSの「動きを減らす」設定も初期値に反映します。

しゃがみで限界に達すると「ヘルニアになりました」、ジャンプやまたぎはそれぞれの原因メッセージを表示します。病名はゲーム内のコミカルな演出です。

これらはゲーム上の設定と演出です。遊具や架空の標識に触れたり飛び越えたりする現実の行動を勧めるものではありません。

画面から離れると自動で一時停止します。「ゲームに戻る」を押すと3秒後に再開します。音は初期状態でオフです。画面下の「音：オフ」を押すとオンにできます。スマートフォン用のタッチボタンも用意しています。

## 身体能力とアイテムの高さ

身長188cm、靴込みの通行判定190cm、股下90cm、垂直跳び75cm、立ち到達252cm、ジャンプ最高到達327cmを基準にします。低いアイテムは252cm以下、高いアイテムは252cm超〜327cmです。高い物は単に空中にいればよいのではなく、現在の手の高度が届くタイミングでEを押します。少し早い入力も0.4秒間予約されるため、頂点の1フレームに合わせる必要はありません。

車線分離ポール、ミニ電車、スーツケース、カラーコーン1個、跳び箱5段は、ゲーム内の専用ルールでSを保持してまたぎます。幅80cmを超える物や、股下に収まらない高さの物にはまたぎが通用しません。パンダ・ゾウ・カメ・ウマのスプリング遊具や、横に並ぶカラーコーン2個はジャンプで回避します。足元が障害物より高い状態で、奥行き全体を通過する必要があります。

## 難易度と安全なイベント生成

速度は0mで1倍、100mで1.4倍、200mで1.9倍、300mで2.4倍、500mで3.1倍、800m以降は3.5倍に滑らかに変化します。イベント間隔は序盤2.5〜3.5秒、中盤1.7〜2.5秒、終盤は安全を優先して1.3〜1.8秒にしています。

イベントの到着時刻を先に決め、加速を見込んで位置を計算します。各イベントは最低3.4秒先に配置します。1秒のジャンプ滞空時間に0.3秒の操作余裕を加え、ジャンプの後でも着地して姿勢を切り替えられます。取得可能距離は到着時の速度を基準に計算し、約0.84秒の時間幅を確保します。

生成時は正しい操作に必要な負荷を保守的に見積もります。通常の候補は予測負荷55%を基準に選び、必要なら延期します。中盤から時々、長い吊り革・網棚・低いバス天井の通路が現れます。これらは完全に回復してから入るよう配置し、約3.9秒の通過と操作の余裕で負荷が80〜95%に達する緊張感を作ります。通過後は回復できる入口と低いアイテムだけを出し、負荷が下がる時間を確保します。加速中も通路を抜ける時間が一致するよう、前後端の位置を計算します。

イベントの生成時刻も到着予定に合わせ、長い区間を入れても遠方イベントが無制限に積み上がらないようにしています。通常プレイ中の表示は、上部中央に次の1イベントの名前だけです。障害物ごとの高さや正解は表示しません。右端の190cm目盛りはプレイヤーの立位の基準です。

分かりにくい・役割が重複する旧障害物21種類を整理し、19種類の障害物と21種類のアイテムにしました。元の電車入口・地下通路・倉庫梁・階段下などを外し、維持する吊り革・網棚・バス天井・部室・自宅の鴨居・学校と店舗のドア・動物型遊具に、ミニ電車・スーツケース・横2個のコーン・5段の跳び箱を組み合わせます。エリアは180mごとに変わり、公園は動物型遊具を優先します。イベントは到着するエリアに自然な物から選びます。

## 見やすい追従カメラ

視点を少し上げ、斜め下を見下ろして前方の地面を広く見せます。キャラクターは画面下寄りに置き、小さい障害物と画面上で重なったときだけ半透明になります。キャラクターと障害物の描画には同じ高さ換算を使います。

## チュートリアルの設定

「次回からチュートリアルを表示しない」をチェックすると、スキップボタンが有効になります。チェックだけではゲームは開始しません。スキップボタンを押すと通常プレイが始まります。

## 開発と調整

| ファイル | 内容 |
| --- | --- |
| `index.html` | 日本語UI、画面、ボタン |
| `style.css` | レイアウト、デザイン、レスポンシブ表示 |
| `game-engine.js` | 状態、物理、負荷、イベント、衝突、チュートリアル |
| `game.js` | Canvas描画、入力、フォーカス、一時停止、音 |
| `188cm_RUN.ipynb` | 完成版を内包するColabノートブック |
| `colab_cells.py` | 同じ内容を3セルとして貼り付けられるPythonコード |
| `tools/build_colab.py` | ゲームのソースからColab用成果物を再生成 |
| `tests/` | ルール、ブラウザ操作、ノートブックの検証 |

`game-engine.js` 冒頭の `CONFIG` で速度、イベント間隔、ジャンプ、負荷を調整できます。物理は秒を基準に120Hzの小ステップで計算し、描画にはrequestAnimationFrameを使います。障害物は通過中の全時間に衝突判定を行います。身長188cmに靴の高さ2cmを加え、描画と通行判定の頭頂は190cmで一致します。股下90cm、垂直跳び75cm、立ち到達252cm、ジャンプ到達327cmを定数管理しています。ジャンプ中の手の高度と足元の高度を別々に判定し、手の当たり判定には2cmの余裕があります。

ローカルで起動する場合：

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。Pythonがない場合でも、`index.html` を直接開いて遊べます。

ソース変更後の確認：

```sh
node --check game-engine.js
node --check game.js
node tests/engine.test.js
node tests/virtual-player.cjs
python3 tools/build_colab.py
python3 tests/colab_test.py
```

`node tests/final-browser.cjs` はカメラ、単一のイベント名、警告と演出設定、E予約、原因別メッセージを追加検証します。

ブラウザテストはPlaywrightとChromiumを使います。開発テスト用に `npm install --no-save playwright` を実行し、Chromiumを用意してから、上記HTTPサーバーを起動した状態で `node tests/browser.cjs` を実行します。必要なら `CHROMIUM_PATH` と `GAME_TEST_URL` でパスとURLを指定できます。通常プレイにはこれらのインストールは不要です。

`?test` を付けたURLだけに内部状態を確認できるテスト用オブジェクトを公開します。通常のURLでは公開しません。

## 検証範囲

24件のルールテストに加え、仮想プレイヤーを50種の乱数列、30・60・120fpsで動かし、計100,000イベントを通過しました。全40種類と全7エリアが含まれ、疲労最大は88.17%でした。これは検証した列での結果で、すべての乱数列の数学的証明ではありません。[詳しい結果](TESTING.md)を参照してください。

クラウド環境のChromiumで、実際のキーボード入力とiframe内の操作を検証します。Colab用コードはローカルで3セルを実行し、HTML生成、HTTP応答、サーバー再実行、iframe表示APIへの引数を検証します。

Google Colab本体へのログインとColab独自のプロキシ表示は、この開発環境から直接確認できません。実際のColabでの表示確認は、上記の3セルを順番に実行して行ってください。
